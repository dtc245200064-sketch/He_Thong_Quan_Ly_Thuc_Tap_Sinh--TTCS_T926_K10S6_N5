# Giao Diện Đăng Nhập - Hệ Thống Quản Lý Thực Tập Sinh

Giao diện đăng nhập 2 cột hiện đại chia làm 4 vai trò, viết bằng **HTML** và **CSS** thuần ngắn gọn, dễ hiểu:

## 1. Cột trái (Banner giới thiệu)
- Logo và slogan: "KẾT NỐI TRI THỨC - MỞ LỐI TƯƠNG LAI".
- 4 tính năng: Quản lý thực tập sinh, Quản lý doanh nghiệp, Theo dõi tiến độ, Báo cáo thống kê.
- Hình ảnh banner thực tập sinh.

## 2. Cột phải (Form đăng nhập)
- 4 vai trò: Admin, HR, Master, Thực tập sinh.
- Ô nhập Tên đăng nhập và Mật khẩu có icon và nút ẩn/hiện mắt.
- Ghi nhớ đăng nhập và Quên mật khẩu.
- Nút "ĐĂNG NHẬP" và nút "Đăng nhập với Google".
- Dòng bảo mật dữ liệu ở chân form.

## 3. Cách mở
- Nhấp đúp chuột vào file [index.html](index.html) để mở trên trình duyệt.
